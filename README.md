# Library Management System (Java OOP + CLI)

This is a simple **Library Management System** built using **Java Object-Oriented Programming (OOP)** concepts.  
It is a **menu-driven console application** that allows users to perform core library operations like:

- Adding books and users
- Issuing and returning books
- Viewing all books and registered users

All input/output operations are handled through the Java `Scanner` class.

---

## Features Implemented

- `Book`, `User`, and `Library` classes
- Book issue and return tracking
- Menu-based user interface using loops and conditionals
- Object-oriented principles (Encapsulation, Abstraction)
- Data structures used: `ArrayList`, `HashMap`

---

## Technologies Used

- Java (JDK 8+)
- Scanner class for input
- Collections (ArrayList, HashMap)
- Command Line Interface (CLI)

---

##  How to Run

1. Clone or download this repository.
2. Open the project in any Java IDE (e.g., Eclipse, IntelliJ, VS Code).
3. Run the `LibraryManagementSystemScanner.java` file.
4. Follow the console menu to perform operations.
